# Phase 2-2 閲覧品質指標 手動確認項目

## 指標カード

1. 専用解析ページの上部に、訪問者数、PV、平均閲覧時間、直帰率、1訪問あたりPVの5カードが表示されることを確認する。
2. PCでは5列、スマートフォンでは2列になり、最後のカードが横幅いっぱいになることを確認する。
3. 訪問回数がカード下の補助情報へ表示されることを確認する。
4. 各「？」をマウス、キーボード、タップで操作し、短い説明を確認する。
5. WordPressダッシュボードウィジェットは訪問者とPVの2カードのままであることを確認する。

## 平均閲覧時間

1. Phase 2-1導入後に開始し、終了から30分以上経過した訪問だけが平均へ含まれることを確認する。
2. ページごとの`engaged_seconds`合計を終了訪問数で割った値と表示が一致することを確認する。
3. 60秒未満は「○秒」、60秒以上は「○分○秒」で表示されることを確認する。
4. 終了した訪問がない場合は「集計中」と表示されることを確認する。

## 直帰率と回遊

1. 1ページだけで終了した訪問数を終了訪問数で割った値と直帰率が一致することを確認する。
2. 30分以内の閲覧中訪問が直帰率へ含まれないことを確認する。
3. 1訪問あたりPVが、選択期間のPVを訪問数で割った値と一致することを確認する。
4. 今日、昨日、7日、30日、今月、期間指定で全指標が切り替わることを確認する。
5. 日付移動とグラフの点からの移動でも全指標が同じ日付へ切り替わることを確認する。

## 比較と既存データ

1. 平均閲覧時間は前期間との差を時間で表示することを確認する。
2. 直帰率は前期間との差をポイントで表示し、増加は赤、減少は緑になることを確認する。
3. 1訪問あたりPVは前期間との差をページ数で表示することを確認する。
4. Phase 1時代の有効時間ゼロが平均閲覧時間へ混ざらないことを確認する。
5. 本日を含む期間では補助情報に暫定値であることが表示されることを確認する。
