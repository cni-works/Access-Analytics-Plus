# 時間軸UI 実サイト受入テスト

対象Build: `phase2-5-ui4.20260828.1`

管理画面の開発者ツールで、`assets/js/admin-ui4.js` と `assets/css/admin-ui4.css` が読み込まれていることも確認する。旧ファイル名が表示される場合は、プラグインまたはCDNのキャッシュが残っている。

## 日単位

1. 「今日」を押し、中央の日付、時間別グラフ、主要指標、流入元、人気ページ、デバイスが今日に揃うことを確認する。
2. 左矢印を3回押し、昨日、おととい、3日前へ1日ずつ移動することを確認する。
3. 右矢印で今日まで戻り、今日では右矢印が無効になることを確認する。
4. 「日付を選ぶ」から過去日を選び、その日の時間別表示になることを確認する。
5. 「今日へ戻る」で今日へ戻ることを確認する。

## 7日・30日・今月

1. 7日表示で左右矢印を押し、同じ7日幅で前後に移動することを確認する。
2. 30日表示で左右矢印を押し、同じ30日幅で前後に移動することを確認する。
3. 今月表示で前月へ移動し、右矢印で今月へ戻ることを確認する。
4. 今日を含む期間では右矢印が無効になることを確認する。
5. 「最新期間へ戻る」で選択中の7日、30日、今月の最新期間へ戻ることを確認する。

## グラフ

1. 左側のY軸目盛りと薄い補助線から、おおよその訪問者数を読み取れることを確認する。
2. PCでポイントへマウスを重ね、日付または時間、訪問者、PVが表示されることを確認する。
3. スマートフォンでポイントをタップし、同じ情報が表示されることを確認する。
4. 7日・30日グラフのポイントを選び、その日の時間別表示へ移動することを確認する。
5. 10点以下のPCグラフでは、アクセスがある点だけ実数が表示されることを確認する。

## 時間別・日別一覧

1. 日単位では、初期状態でアクセスがあった時間だけが表示されることを確認する。
2. 「すべての時間を見る」で00:00〜23:00の24行が表示されることを確認する。
3. 7日表示では全日、30日表示ではアクセスがあった直近最大10日が初期表示されることを確認する。
4. 「すべての日を見る」で期間内の全日が表示されることを確認する。
5. 日別一覧の行を押し、その日の時間別表示へ移動することを確認する。
6. 各行に訪問者、PV、平均閲覧時間が表示されることを確認する。終了済み訪問がない行は「集計中」となる。

## スマートフォン

1. 320px、375px、430px相当の幅でページ全体に横スクロールが出ないことを確認する。
2. 日付矢印、日付選択、期間ボタンのタップ領域が十分であることを確認する。
3. 時間別・日別一覧の日時、訪問者、PVが折り返しで読みにくくならないことを確認する。
4. ツールチップが画面の左右からはみ出さないことを確認する。

## 期間連動

各移動後に、訪問者、PV、平均閲覧時間、直帰率、1訪問あたりPV、グラフ、一覧、流入元、人気ページ、デバイス、除外件数が同じ開始日・終了日で更新されることを確認する。
