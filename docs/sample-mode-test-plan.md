# サンプル表示・平均閲覧時間 受入テスト

対象Build: `phase2-5-ui4.20260828.1`

## 日付選択

1. 1日表示で「日付を選ぶ」を押す。
2. ネイティブの日付選択UI、または操作可能な日付入力欄が表示されることを確認する。
3. 数週間前の日付を選び、その日の主要指標、時間別グラフ、時間別一覧、流入元、人気ページ、デバイス、除外件数へ一括して切り替わることを確認する。
4. 320px幅でも入力欄やボタンが画面からはみ出さないことを確認する。

## 一覧の平均有効閲覧時間

1. 今日・昨日・過去日の時間別一覧に、訪問者、PV、平均閲覧時間が表示されることを確認する。
2. 7日・30日・今月の日別一覧にも同じ3指標が表示されることを確認する。
3. 終了済み訪問がない時間・日は「平均閲覧 集計中」となることを確認する。
4. 一覧下の説明が「その時間・日に開始した終了済み訪問」を基準としていることを確認する。

## サンプル表示

1. 設定 → サンプル表示でON、規模「標準」を保存する。
2. 専用解析画面の上部に「サンプルデータ表示中」バッジが表示されることを確認する。
3. 今日・7日・30日・今月を切り替え、主要指標、グラフ、一覧、流入元、人気ページ、デバイス、比較値に自然なサンプルが表示されることを確認する。
4. 同じ期間を再度開き、数値が変わらないことを確認する。
5. 「サンプルデータを再生成」を押し、数値が変更され、その後は再び固定されることを確認する。
6. 少なめは1日5〜30訪問、標準は30〜100訪問、多めは100〜500訪問程度になることを確認する。
7. PV ÷ 訪問と1訪問あたりPV、時間・日別合計と期間合計、流入元・デバイス・人気ページの合計が整合することを確認する。

## 実データとの分離

1. サンプルONの前後で実データベースのpageviews、sessions件数が変化しないことを確認する。
2. サンプルON中も未ログインブラウザーの実アクセスが通常どおり計測されることを確認する。
3. WordPressダッシュボードウィジェットは実データのままであることを確認する。
4. サンプルをOFFにすると専用解析画面が直ちに実データへ戻り、バッジが消えることを確認する。

## 表示幅

PC、320px、375px、430pxで横スクロールが発生せず、一覧の4要素が読み取れることを確認する。
