# Access Analytics Plus 1.0.0

小規模サイトの運営者が、WordPress管理画面からアクセス状況と問い合わせ導線を簡単に確認するための最初の正式版です。

## 主な機能

- confirmedアクセスを基準にした訪問者・訪問・PV集計
- 平均有効閲覧時間・直帰率・1訪問あたりPV
- 時間別・日別グラフ、時間別詳細、流入元、人気ページ、デバイス
- 自動アクセス診断、管理者・権限・IP・Bot除外
- 国フィルターと日本国内の都道府県別アクセス分析
- Site Kit接続済みサイトでのGoogle検索キーワード表示
- AI相談用Markdownレポート
- 電話・LINE・お問い合わせ導線・Contact Form 7送信成功の簡易CV解析
- WordPressダッシュボードウィジェット、スマートフォンUI、サンプル表示

## プライバシー

- 生IPアドレスとUser-Agent全文を解析データとして保存しません。
- 国・都道府県判定は推定値であり、携帯回線・VPN等では実所在地と異なる場合があります。
- AI相談用レポートはAAPから外部AIへ自動送信しません。
