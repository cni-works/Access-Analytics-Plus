# Access Analytics Plus 0.5.0 Beta

「アクセス解析＋」の最初の公開ベータ版です。

## 主な機能

- 今日・昨日・7日・30日・今月・期間指定によるアクセス確認
- カレンダーと前後移動による過去期間の確認
- 訪問者数・PV・平均有効閲覧時間・直帰率・1訪問あたりPV
- 時間別・日別の棒グラフと数値一覧
- 流入元・人気ページ・デバイスの表示
- WordPressダッシュボードの簡易アクセス解析ウィジェット
- Bot・管理者・WordPress権限・IPアドレスによる除外
- 詳細データ保存期間と安全な分割削除
- 実データへ影響しないサンプル表示
- GitHub Releaseを利用したWordPress標準更新通知

## ベータ版について

実運用環境での確認を目的としたベータ版です。本番サイトへ導入する場合は、事前にWordPressサイトとデータベースをバックアップしてください。

不具合が発生した場合に備え、更新前のプラグインZIPも保管してください。
