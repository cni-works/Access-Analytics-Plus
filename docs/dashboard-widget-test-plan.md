# ダッシュボードウィジェット 実サイト受入テスト

対象Build: `phase2-5-ui4.20260828.1`

## 期間切替

1. WordPressダッシュボードを開き、初期選択が「今日」であることを確認する。
2. 今日の訪問者、今日のPV、24時間の時間別グラフが表示されることを確認する。
3. 「昨日」を押し、訪問者・PV・時間別グラフが昨日へ切り替わることを確認する。
4. 「7日」を押し、訪問者・PV・7点の日別グラフが直近7日へ切り替わることを確認する。
5. 「今月の訪問者」はどのタブでも現在の月の値を保つことを確認する。
6. 人気ページが選択中の期間に連動することを確認する。

## グラフ操作

1. 読み込み直後、グラフ左下を含め黒い丸や空の吹き出しが表示されないことを確認する。
2. PCでは各ポイントへマウスを重ねた間だけ、時間または日付・訪問者・PVが表示されることを確認する。
3. ポイント外へ移動すると吹き出しが消え、グラフ外に要素が残らないことを確認する。
4. スマートフォンではポイントをタップした場合だけ詳細が表示されることを確認する。

## サンプル表示との分離

1. 設定でサンプル表示をONにし、専用解析画面に「サンプルデータ表示中」が出ることを確認する。
2. WordPressダッシュボードへ戻り、ウィジェットは実データのままでサンプルバッジが出ないことを確認する。

## レスポンシブ

1. 320px、375px、PC幅で横スクロールが発生しないことを確認する。
2. スマートフォンで「今日・昨日・7日」の各ボタンが44px以上の高さで押しやすいことを確認する。
3. 訪問者・PV・グラフ・今月・人気ページ・詳細ボタンが自然な順序で収まることを確認する。

## 専用解析画面の回帰

1. 今日・昨日・7日・30日・今月・期間指定が従来どおり切り替わることを確認する。
2. 専用解析画面でも、通常時に空の黒い吹き出しが表示されないことを確認する。
3. サンプル表示、日付選択、時間別・日別一覧、平均閲覧時間が従来どおり表示されることを確認する。
