# Phase 1 手動確認項目

## 有効化

1. WordPress 6.8以上、PHP 8.1以上の検証サイトへプラグインを配置する。
2. 管理者で有効化し、致命的エラーが発生しないことを確認する。
3. 管理メニューに「アクセス解析」が表示されることを確認する。
4. 専用テーブル6個と日次クリーンアップイベントが作成されたことを確認する。

## 計測

1. ログアウトした通常ブラウザーで公開ページを2ページ以上閲覧する。
2. 同じブラウザーでは30分以内の閲覧が同じ訪問として集計されることを確認する。
3. Cookieを削除した別ブラウザーが別の訪問者として集計されることを確認する。
4. ログイン中の管理者による公開ページ閲覧が集計されないことを確認する。
5. 外部サイト、検索サイト、SNSからの遷移が分類されることを確認する。
6. ページタイトルとPVが人気ページへ表示されることを確認する。

## 管理画面

1. 今日、昨日、7日、30日、今月、期間指定を切り替える。
2. 90日を超える期間指定が拒否されることを確認する。
3. 訪問者、PV、訪問、前期間比、グラフ、流入元、人気ページを確認する。
4. グラフの点をマウス、キーボード、タップで選択し、値を確認する。
5. 7日・30日グラフの点を選択し、その日の時間別表示へ移動することを確認する。
6. 日別表示の左右矢印で前日・翌日へ移動し、カード、グラフ、流入元、人気ページが同じ日付へ切り替わることを確認する。
7. 今日では翌日ボタンが無効になり、過去日では「今日へ戻る」が表示されることを確認する。
8. 期間指定で未来日と91日以上の期間が拒否されることを確認する。
9. WordPressダッシュボードに今日の訪問者・PV、7日間グラフ、今月の訪問者、人気ページが表示されることを確認する。

## スマートフォン

1. 375px幅で横スクロールが発生しないことを確認する。
2. 「スマホで見る」からURLをコピーできることを確認する。
3. QRコードを実機で読み取り、解析ページURLが開くことを確認する。
4. 未ログイン状態ではWordPressログイン画面へ移動し、ログイン後に解析ページへ戻ることを確認する。
5. ホーム画面へ追加したリンクから同じ画面を開けることを確認する。

## キャッシュとセキュリティ

1. 利用予定のページキャッシュを有効にした状態でもログアウト訪問を計測できることを確認する。
2. 権限のないユーザーが解析ページとレポートREST APIを閲覧できないことを確認する。
3. 外部オリジンからの収集リクエストが拒否されることを確認する。
4. プラグイン停止後に解析データが残り、再有効化後に再利用できることを確認する。
5. 「削除時にデータも削除」が初期OFFであることを確認する。
