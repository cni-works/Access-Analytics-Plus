# Phase 2-3 デバイス 手動確認項目

## 表示

1. 専用解析ページの下部に「デバイス」カードが表示されることを確認する。
2. データがあるスマートフォン、PC、タブレットが、訪問の多い順に比率バーで表示されることを確認する。
3. 判定できない端末がある場合だけ「その他」が表示されることを確認する。
4. 各比率が選択期間の訪問数を基準に計算されていることを確認する。
5. デバイスが0件の期間では、アクセスがないことを示す案内が表示されることを確認する。

## 期間連動

1. 今日、昨日、7日、30日、今月、期間指定でデバイス比率が切り替わることを確認する。
2. 日付移動の左右矢印でデバイス比率も同じ日付へ切り替わることを確認する。
3. グラフの点から日別表示へ移動した場合も同様に切り替わることを確認する。
4. 同じ訪問で複数ページを見ても、デバイスの訪問数が重複しないことを確認する。

## 端末判定

端末分類は訪問開始時に固定されます。更新前から開いているブラウザーではなく、シークレットウィンドウを使うか、30分以上空けた新しい訪問で確認します。

1. iPhoneまたはAndroidスマートフォンから閲覧し、「スマートフォン」へ集計されることを確認する。
2. WindowsまたはMacのPCから閲覧し、「PC」へ集計されることを確認する。
3. iPadまたはAndroidタブレットから閲覧し、「タブレット」へ集計されることを確認する。
4. iPadで「デスクトップ用Webサイトを表示」を使用しても、可能な範囲でタブレットへ分類されることを確認する。
5. 既存のPhase 1・Phase 2データも、保存済みの分類で表示されることを確認する。

## レスポンシブと既存機能

1. 375px幅でデバイスカードによる横スクロールが発生しないことを確認する。
2. 比率バーと説明の「？」がタップできることを確認する。
3. WordPressダッシュボードウィジェットにはデバイス情報を追加せず、従来の簡潔な表示を維持していることを確認する。
4. Phase 2-1の有効閲覧時間とPhase 2-2の3指標が従来どおり動作することを確認する。
