# Phase 2-1 有効閲覧時間 手動確認項目

## 基本計測

1. ログアウトしたブラウザーで公開ページを開き、15秒以上表示する。
2. `wp_aap_pageviews.engaged_seconds`が約15秒以上へ更新されることを確認する。
3. 75秒以上表示し、15秒送信後も約60秒間隔で値が増えることを確認する。
4. ページを閉じる、または別ページへ移動したとき、最後の有効秒数が送信されることを確認する。
5. 送信済みと同じ秒数を再送しても値と日次合計が増えないことを確認する。
6. ページ表示直後に1800秒を送信しても、実際の経過時間を大きく超えて保存されないことを確認する。

## 表示状態と無操作

1. 別タブへ移動している間は有効秒数が増えないことを確認する。
2. 元のタブへ戻ると計測が再開することを確認する。
3. 5分間操作せずに表示を続けると加算が止まることを確認する。
4. 停止後にスクロールまたはタップすると加算が再開することを確認する。
5. 30分を超えて表示しても1ページの有効秒数が1800秒を超えないことを確認する。

## ブラウザーと通信

1. PC版Chrome、SafariまたはFirefoxで計測できることを確認する。
2. iPhone Safariでタブ移動、画面ロック、ページ離脱時の動作を確認する。
3. Android Chromeで同様の動作を確認する。
4. 複数タブで別ページを開き、それぞれ別のページビューへ時間が保存されることを確認する。
5. 通信を再送しても二重加算されず、閲覧画面の操作を妨げないことを確認する。

## セキュリティと既存機能

1. 改変した署名トークンと期限切れトークンが403で拒否されることを確認する。
2. 外部オリジンからの有効時間送信が拒否されることを確認する。
3. ログイン中の管理者とBotには有効時間トークンが発行されないことを確認する。
4. Phase 1の訪問者、PV、訪問、流入元、人気ページが従来どおり集計されることを確認する。
5. 日次再集計後も`engaged_seconds`が0へ戻らないことを確認する。
