# AI相談用レポート V1

## 目的

AAPが保持する集計済みの公開サイト解析情報を、利用者が自分で選んだAIへ添付できるMarkdownに整形する。AAP自身はAI APIへ接続せず、レポートを外部へ自動送信しない。

## 処理境界

1. 既存のAnalyticsおよびSearch Consoleサービスからデータを読み取る。
2. `AI_Report`が出力形式に依存しないReport Payloadへ正規化する。
3. `AI_Report_Markdown`がPayloadをMarkdownへ変換する。
4. 管理画面でプレビュー後、`admin-post.php`から再検証・再生成して直接ダウンロードする。
5. ダウンロードしたファイルを、利用者自身が普段使用しているAIへ添付する。

生成済み本文や相談内容はOption、解析テーブル、uploadsへ保存しない。

## 入力と保存

保存するサイト基本情報は、サイトの目的、主な対象地域、重点サービスの3項目だけとする。現在の悩み、AIへの質問、問い合わせ件数はリクエスト中だけ利用する。期間は直近7日、28日、3か月、または最大90日の期間指定に対応する。

## Payload

Payload schema version 1は、サイト情報、相談内容、対象期間と同じ長さの比較期間、データ充足度、アクセス指標、流入元、公開ページ、デバイス、国・都道府県、任意のSearch Console結果、取得できなかった項目を保持する。表示文字列とデータ取得を分離し、将来の別Rendererへ再利用できる構造とする。

## 安全性

- 生IP、各種訪問識別子、Bot診断、認証情報、WordPressユーザー情報、サーバー情報、個人単位の行動は含めない。
- 人気ページは公開ページに限定し、クエリ文字列とfragment、管理・ログイン・REST系Path、外部ドメインを除外する。
- Search Console検索語句ではメールアドレス、電話番号らしい値、8桁以上の連続数字をマスクする。
- Markdown表を壊す制御文字、改行、区切り記号を正規化・エスケープする。
- ページ名、Path、検索語句などの外部由来文字列を命令として扱わない旨をAI相談文へ明記する。
- サンプル表示中はプレビュー生成とダウンロードを停止する。

## ダウンロード

ダウンロードはPOST、AAP閲覧権限、nonce、入力と期間の再検証を必須とする。`text/markdown; charset=UTF-8`、添付ファイル名、`nosniff`、no-cacheを設定し、既存output bufferを破棄してMarkdownだけを返す。

## Search Console

既存の`Search_Console_Service`だけを利用する。7日・28日・3か月はGoogle側の1日遅延を考慮した既存期間定義に従う。期間指定ではV1の既存サービスが任意日付を受け付けないためSearch Consoleを含めず、その理由をレポートへ明記する。未導入、停止、未接続、権限不足、再認証、通信、schemaの各状態もレポート本体を妨げない。

## 充足度

期間と確認済み訪問数を別々に評価し、生成は禁止しない。

- 期間: 0～2日「非常に少ない」、3～6日「少ない」、7～27日「短期傾向」、28日以上「標準的な分析期間」
- 訪問数: 0～4「非常に少ない」、5～19「少ない」、20～49「小規模サイトの傾向確認向き」、50以上「十分」

期間または訪問数が少ない場合は、傾向を断定せず参考情報として扱う注意を自動挿入する。
