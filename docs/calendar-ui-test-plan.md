# カレンダー・一覧の連動（2026-09-10）

Build .5: 初期カレンダーは選択期間末尾を含む週と前週の2週間表示。
「月全体から選ぶ」で全月表示を開ける。前月・翌月ボタンも全月表示へ移る。
専用画面のグラフは薄い青のPVを背面、濃い青の訪問者数を前面に重ねた棒グラフ。
両系列は共通のゼロ始まりの目盛を使い、積み上げない。小型ウィジェットは従来表示。PC幅1000px以上では左にカレンダー、右に指標を配置する。
狭い画面ではグラフを幅に合わせて再描画し、カードの高さを抑える。

## 表示方針

初心者が日付・グラフ・実数を見渡し、気になった日から時間別へ進める構成とする。
月をめくる操作はカレンダーだけに作用し、日付選択で初めて解析対象を切り替える。
青い日付は表示対象期間、枠線は今日。アクセスの有無を表す色ではない。
グラフの点と一覧行は、マウス・フォーカス操作で対応箇所を強調する。
個別ユーザー追跡、地域分析、ページ別の新しい集計は追加していない。

## WordPressでの手動確認

- 通常データ・サンプル表示で、初期期間とカレンダーの青い範囲が一致する。
- 前月・翌月はカレンダーのみを変更し、数値・グラフは変えない。
- 日付を選ぶと同日の時間別表示へ進み、表示日が読み取れる。
- 元の期間へのリンクで、移動前の対象期間へ戻る。
- 期間指定で月をまたいでも、表示している月の対象日が強調される。
- グラフの点にマウスを重ねると、表示されている対応行が強調される。
- 日別行のフォーカス・マウス操作で対応するグラフの点が強調される。
- 未来日は選択できない。アクセス0件でも過去日を選択できる。
- スマホで日付ボタンを押せて、横スクロールが発生しない。
- WordPressダッシュボードの小型ウィジェットにはカレンダーを追加しない。

自動テストは既存の admin-ui-regression.js に追加。月閲覧時の通信なし、
日付選択・復帰、キーボード、年またぎ、うるう年、未来日、連動表示を確認する。
